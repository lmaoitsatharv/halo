## Saving usage
- Whenever possible, delegate small, mechanical work to the `quick-fixer` subagent (Haiku): typo fixes, renames, formatting, small one-file edits, simple find-and-replace. Give it the exact file and change.
- Keep the main model for design decisions, debugging, multi-file changes and anything needing judgment.
- Don't delegate when doing it yourself is a single quick edit you already have in view (the hand-off would cost more than it saves).
